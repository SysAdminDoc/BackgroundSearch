BackgroundSearch v2.7.1

Open search results in another tab without losing your place. This package includes the extension, its license and this setup guide. You don't need a build tool to install it.

Chrome and Chromium browsers

  1. Extract the Chrome ZIP into a permanent folder. Don't leave it in a temporary downloads preview.
  2. Open chrome://extensions in Chrome or edge://extensions in Edge.
  3. Enable Developer mode, click Load unpacked, then select the extracted folder containing manifest.json.
  4. Pin BackgroundSearch from the browser's Extensions menu. Open its settings and choose your search engines.

Keep the extracted folder. Your browser reads the extension from it. To update, export your settings, replace the files in that same folder with the next Chrome package, then click Reload on the extension card. Reload open web pages too.

The secondary CRX is for compatible self-hosted distribution systems. It isn't a Chrome Web Store package and isn't the recommended drag-and-drop installer.

Firefox 142 or newer

  1. Extract the Firefox ZIP. The Chrome manifest won't work as a Firefox package.
  2. Open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and select the extracted manifest.json.
  4. Allow access to the sites where you want selection and tab controls to work.

This Firefox package is unsigned and temporary. Firefox removes temporary add-ons when it restarts. No permanent signed Firefox installer is included. Chrome's side panel and automatic result-tab groups aren't available in this Firefox build.

Try your first search

Google is enabled initially. Select text on a normal web page, right-click, and choose its BackgroundSearch item. Enable Quick Menu on Selection if you'd prefer buttons next to selected text. Browser settings pages and extension-store pages restrict content scripts.

For address-bar search, type bs, then a space, followed by your query. With YouTube enabled, !yt browser tabs chooses YouTube. !gh browser tabs chooses GitHub when enabled.

Your data and backups

Use Export in the engine settings to save a JSON backup. Settings use browser sync storage, but local usage counts and side-panel history don't sync. Providers receive the searches you send them. Engine icons request favicons from Google. Read the privacy details before adding a private-site engine.
